# Employee Management System using SQL

## 📌 Project Overview

The Employee Management System is a relational database project developed using **MySQL** to manage and organise employee-related information within an organisation. The project demonstrates database design, table relationships, SQL programming, and reporting techniques by integrating multiple modules such as employee details, departments, attendance, leave management, and payroll.

This project was created to strengthen practical SQL skills, including database design, data manipulation, and query optimisation using real-world business scenarios.

---

## 🎯 Objectives

- Design a structured relational database for employee management.
- Store and manage employee information efficiently.
- Maintain department and job-related details.
- Track employee attendance and leave records.
- Manage salary and bonus information.
- Generate meaningful reports using SQL queries.
- Demonstrate the use of advanced SQL concepts.

- Employee
- Department
- JobDepartment
- Attendance
- LeaveManagement
- SalaryBonus

Each table is linked using foreign keys to maintain data integrity and support efficient querying.
